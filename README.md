# Análise de Dados de Energia — ONS

## Sobre o projeto

Este repositório contém as resoluções das atividades propostas na disciplina, desenvolvidas pelo grupo durante as aulas 03, 04 e 05.

A atividade tem como objetivo aplicar conceitos de **programação, análise e tratamento de dados**, utilizando dados reais relacionados ao consumo/carga de energia elétrica no Brasil.

As análises foram desenvolvidas em Python, utilizando ferramentas e bibliotecas voltadas para manipulação, exploração e visualização de dados.

## Objetivos

* Praticar a coleta e análise de dados utilizando Python;
* Trabalhar com dados provenientes de uma API pública;
* Realizar tratamento e organização dos dados;
* Construir e analisar DataFrames;
* Calcular indicadores estatísticos;
* Criar recortes dos dados a partir de critérios definidos;
* Produzir visualizações para auxiliar na interpretação dos resultados;
* Desenvolver as atividades propostas nas aulas 03 e 04.

## Fonte dos dados

Os dados utilizados na análise de energia elétrica foram obtidos por meio da API pública do **Operador Nacional do Sistema Elétrico (ONS)**.

* **Portal de dados do ONS:** https://dados.ons.org.br/
* **Conjunto de dados — Carga Verificada:** https://dados.ons.org.br/dataset/carga-energia-verificada
* **API utilizada:** https://apicarga.ons.org.br/prd/cargaverificada

A análise utiliza dados de carga elétrica da área de **São Paulo (SP)**, considerando o período definido na atividade.

## Análise dos dados

No notebook principal, foram realizadas etapas de:

1. Consulta dos dados por meio da API pública do ONS;
2. Preparação dos dados retornados pela API;
3. Construção e inspeção do DataFrame;
4. Identificação e tratamento dos dados;
5. Análise estatística da carga elétrica;
6. Criação de critérios para seleção de registros;
7. Geração de gráficos;
8. Interpretação dos resultados;
9. Elaboração de um relatório técnico com as principais conclusões.
